Common questions

What people usually assume.

Assumption

"Our tests pass, so we're secure."

In practice

Tests check the path a customer takes. Attackers take other paths: changing an ID, replaying a request, skipping a step. Tests rarely look for those.

Assumption

"We had a pentest in March, so we're covered."

In practice

The pentest covered the code as it was in March. Every release since then has shipped without a security check.

Assumption

"A scanner is the same as a pentest."

In practice

Scanners match known patterns. Testers think. Fortis adds fintech-specific patterns in the workflow, but you still need people for the deep work.
